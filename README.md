# Daily Amazon Stock Price Prediction (Hourly)

An end-to-end MLOps project predicting Amazon hourly stock prices using a Long-Short Term Memory network. The project was created to showcase a production-grade machine learning workflow, which involves auto-generated feature engineering, model training, daily inference pipeline, and model monitoring.

## Features

* Hourly Amazon stock price prediction using LSTM
* Automated daily model feature engineering using Feast
* Daily model inference pipeline for prediction generation
* Weekly model retraining and evaluation
* Local ML model registry storing the best three models according to RMSE
* Automatic model selection based on the lowest Root Mean Squared Error
* Prediction vs actual stock price tracking
* GitHub Actions-based model orchestration
* Modular and production-grade ML pipeline
## How It Works

1. The latest hourly stock price data for Amazon is retrieved
2. Technical indicators are generated and stored in Feast as features
3. An hourly inference pipeline is executed, predicting the next trading day’s stock prices
4. Predictions are stored for later evaluation
5. The model is retrained on a weekly basis using the newest data
6. If the retraining results in a better-performing model, it is stored in the registry replacing the worst-performing one

## Retraining Strategy
Model retraining happens every week with storing the best three versions in the registry. The model is retrained on the latest data if the test error is lower than the highest error among the three best models. The lowest error model is used for inference.
